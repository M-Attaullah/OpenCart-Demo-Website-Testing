# 🧪 OpenCart Demo – Software Testing Project

A Software Quality Engineering project focused on testing the **OpenCart Demo Website** using multiple software testing techniques, test cases, defect reporting, and software metrics.

The project was developed as part of **Software Quality Engineering & Lab (SE-343 / SE-343L)** and demonstrates practical application of functional and non-functional testing concepts on a real web-based e-commerce application.

## 📌 Project Overview

The **OpenCart Demo Website** is an online shopping application where users can browse products, search for items, add products to a cart, and proceed through the checkout process.

The main objective of this project was to evaluate the application's functionality, usability, reliability, compatibility, security, and other quality attributes through structured testing.

**Application Under Test:** OpenCart Demo Website
**Demo URL:** https://demo.opencart.com

## 📊 Software Quality Metrics

The project also applies software measurement techniques to selected OpenCart screens.

### Function Point Analysis

Function Point Analysis was performed for three screens:

1. Login Page
2. Product Detail Page
3. Checkout Page

The analysis includes:

* External Inputs (EI)
* External Outputs (EO)
* External Inquiries (EQ)
* Internal Logical Files (ILF)
* External Interface Files (EIF)
* Unadjusted Function Points
* General System Characteristics
* Complexity Adjustment Value
* Adjusted Function Points

### Halstead Metrics

Halstead metrics were calculated for selected screen-related code, including:

* Program Vocabulary
* Program Length
* Estimated Program Length
* Volume
* Difficulty
* Program Effort

### Size-Oriented Metrics

The project also calculates:

* Lines of Code (LOC)
* Source Lines of Code (SLOC)

The calculated metrics were used to compare the relative complexity of the selected code sections.
